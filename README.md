## 🚀 Key Features

### 1. 🌌 Technical Arsenal (3D Planetary Orbit System)
Instead of static skill bars, skills are mapped to an **interactive 3D Solar System** representing different disciplines.
* **Orbits & Tilt:** Click and drag the solar plane to adjust pitch and yaw in real-time. Use the HUD controls to toggle between 2D flat projections and 3D ecliptic views.
* **Scan Telemetry:** Hover over or click on any celestial planet to query its technical stack in the scanning drawer.
* **Speed & Zoom:** Adjust orbital speeds or zoom into specific rings using standard mouse wheel inputs (`Ctrl + Scroll`) or the HUD interface.

### 2. 🎛️ Diagnostics Terminal Drawer (`IDE DIAGNOSTICS`)
A VSCode-inspired collapsible developer shell sits at the bottom of the page. It features:
* **Interactive Command Parser:** Type standard terminal commands directly into the prompt.
* **Easter Eggs:** Execute specific command hooks to unlock hidden visual elements.
* **Multi-Tab Pane:** Switch between `TERMINAL`, `PROBLEMS` (0 warnings), `OUTPUT`, and the `DEBUG CONSOLE`.

### 3. 🛸 Retro Arcade: Space Invaders
Embedded within the **Contact Section** is a playable retro Space Invaders mini-game to keep visitors engaged while they compose their transmissions. High scores trigger celebratory canvas-confetti bursts!

### 4. 🎨 Ambient Customization
* **Dynamic Theme Engines:** Switch between 4 distinct cyberpunk color configurations:
  * `Electric Obsidian` 💜 (Default Deep Purple & Neon Cyan)
  * `Midnight Emerald` 💚 (Sleek Dark Green)
  * `Solarized Amber` 🧡 (Amber Cyber-telemetry)
  * `Deep Ocean` 💙 (High-tech Sea Blue)
* **CRT Screen Shader:** Retro-futuristic scanline overlays and holographic grid backdrops.
* **Custom Magnetic Cursor:** An interactive hover-responsive hardware cursor.

## 🏃 Getting Started

To spin up this space-cyberpunk portfolio locally, follow these steps:

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### 2. Clone and Install
```bash
# Clone the repository
git clone https://github.com/vb8146649/portfolio-website.git

# Navigate into the project directory
cd portfolio-website

# Install dependencies
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:3000` to inspect the telemetry.

### 4. Build for Production
To generate a production-ready static bundle:
```bash
npm run build
```
